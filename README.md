# 词间 · WordFlow 1.5

中文原生 Android 英语学习应用。内置 Kokoro-82M 英语 INT8 模型，通过 sherpa-onnx 1.12.15 在手机本地合成语音。离线听读不需要 Key、Google 服务或系统 TTS 语音包。

## 安装

[下载 1.5 APK](https://github.com/480284856/EnglishLearningAPP/raw/refs/heads/downloads/kokoro-v1.5/WordFlow-1.5-study-debug.apk)。Android 8.0 以上，ARM64 / ARM32。与此前交付版本使用相同签名，可直接覆盖安装以保留词表、手动例句、API 设置和语音缓存。不要先卸载。模型随包提供，首次打开需解包；建议预留至少 1 GB 空间。

本版尚未完成小米真机验收。小米锁屏中断时，可在应用信息中把省电策略设为「无限制」，并允许通知和锁屏通知。

## 词表与导入

- 首页显示词表，进入词表查看单词；播放控制固定在下方，点开单词查看全部导入例句、编辑或添加自己的例句。
- 首页「导入 CSV」创建一个词表；可多选文件，全部合并到该新词表。进入已有词表后点「＋ 导入文件」，追加到同一词表。文件选择器不支持多选时可逐次追加。
- 去掉词汇首尾空格并忽略大小写去重，保留第一次出现的拼写和顺序。每次遇到重复词，累计词频加 1，列表显示 `×词频`。词频统计导入出现次数，不会自动改变播放次数。
- 重复词的不同导入例句全部保留，相同例句去重；手动例句单独保存，不被导入覆盖。已有词表的词频默认是 1；下次追加导入时会统一合并历史重复行。
- 每文件最多 5 MB / 10,000 行，每批最多 50 文件且合计 20 MB，每词表最多 10,000 个不同词；超过限制或任何文件无效，整批不保存，原词表保留。
- CSV 使用 UTF-8，可含 BOM、CRLF、引号内逗号 / 换行和双引号转义。第一列单词必填，第二列例句可空，也支持只有一列词汇。可选表头 `word,sentence`、`word,example`、`词汇,例句`，单列也可用 `word` / `词汇` 表头。每个字段最多 3500 个 UTF-16 单元。

```csv
word,sentence
apple,An apple fell from the tree.
banana,
pear
apple,I bought a fresh apple.
```

以上导入为 3 个不同词；apple 词频为 2，并保留两条例句；banana 和 pear 没有例句也能导入和播放。

## 播放与收听统计

- 播放顺序：单词 → 全部非空导入例句 → 我的例句 → 可选临时 AI 例句。没有例句时仍播放单词。每词最多 20 条手动例句，可添加、编辑和删除。
- 「整项播放」可选 1 / 2 / 3 次：单词和它的例句为一遍，播完指定遍数后再进入下一词。循环词表独立设置，语速 0.5–1.5×。
- 暂停、继续、上一词、下一词及锁屏 / 通知控制。暂停后继续会重读当前片段。息屏播放由前台媒体服务持有状态和模型；断开耳机或失去音频焦点时暂停。
- 「个人 → 收听时长」显示今日、累计及最近 30 个有收听日期的记录，所有日期的累计数据都会保留。按手机本地日期拆分跨午夜播放。
- 时长读取 AudioTrack 实际播出帧数，包含重复播放、缓存播放和临时例句；合成、预缓存、网络等待、片段间隔和暂停均不计时，暂停前已播部分也累计。界面以秒显示。从 1.5 开始记录，不能补算旧版本未记录的时长。

## 大模型例句与个人设置

「个人」分别配置 DeepSeek / OpenRouter API Key，选择当前服务商。已保存 Key 不回显，留空保留，可独立清除。通过 Android KeyStore AES-GCM 加密保存在本机；不放进词表、源码或请求正文，不支持跟随手机备份迁移。

- **手动生成**：点开单词 →「使用大模型生成例句」，联网生成后可编辑预览，确认保存才加入「我的例句」。离线时提示连接网络；关闭页面或息屏取消手动请求。
- **播放时自动生成临时例句**：在个人页开启开关并「保存设置」（默认关闭）。每遍已有内容播完后，检查已验证的互联网连接和所选 Key，生成并朗读一条新例句。没有已有例句时在读完单词后生成。重复播放及息屏播放时也按每遍调用一次。
- 自动生成只将当前词及部分已有 / 上一次临时例句发给所选服务商，提示避免重复；对完全重复的结果跳过。生成内容不一定正确，模型服务也不能保证每次生成不同语境。
- 临时例句只存在会话内存，不写入词表、不缓存其语音，也不进入预缓存。读完进入下一遍或下一词，不会递归生成无尽例句。
- 无网络、缺 Key、服务错误、重复结果或超过 20 秒时跳过，继续词表。暂停、切词、切表、停止及服务销毁取消请求，过期回调不会插播；继续时可能重新请求。
- 每次请求可能消耗 API 额度和流量，不重试、不自动改用收费模型。客户端取消不保证服务商撤销已处理请求的计费。

服务端点固定为官方 HTTPS，禁止重定向传递 Key，设连接 / 读取超时与响应上限：

| 服务商 | 模型 | 说明 |
| --- | --- | --- |
| DeepSeek | `deepseek-flash`（关闭 thinking） | `https://api.deepseek.com/chat/completions`，按账户规则计费 |
| OpenRouter | 默认 `openrouter/free`，可自填模型 ID | `https://openrouter.ai/api/v1/chat/completions`；免费路由仍需要 Key，额度和可用性由平台决定。其他模型可能收费 |

官方说明：[DeepSeek](https://api-docs.deepseek.com/) · [OpenRouter 免费路由](https://openrouter.ai/openrouter/free/apps)。没有用户 Key，开发时未发送真实模型请求或产生费用。

## Kokoro 语音缓存

- 首次正常播放完整合成后，按文本、声音、语速和模型版本保存音频。命中时直接播放，无需再次合成；启动时仍需加载模型。**临时 AI 例句始终绕过缓存读写。**
- 「预缓存词表」静默生成词表中保存的单词和例句，相同文本去重，已有缓存跳过。可息屏等待或取消，已完成部分保留。预缓存不调用大模型、不增加收听时长。
- 缓存上限 256 MB。普通播放淘汰较久未用文件，批量预缓存到上限停止，避免挤掉此前完成内容。
- CRC32 校验损坏文件，取消生成不提交临时音频。换语速会生成独立缓存。
- 「缓存管理」查看占用和清理；清理缓存不删词表、模型或收听统计。系统可能清理应用缓存，之后可重新合成。
- Android 13 起首次预缓存可申请通知权限；拒绝仍可在页面查看 / 取消。Android 15 dataSync 时限到达会停止预缓存并保留完成部分。

## 代码维护与构建

模块职责、状态流和不变量见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。Java 代码统一使用 google-java-format 1.24.0，可运行 `bash scripts/format-java.sh`，下载工具按 SHA-256 校验。

需要 JDK 17 以上、Android SDK Platform 35 / Build Tools 35.0.0。Gradle wrapper 8.9、AGP 8.7.3。源码 ZIP / Git 不包含大模型和 AAR；下载脚本固定版本并校验官方资源。APK 已内置这些资源，手机不用执行下载。

```sh
python3 scripts/prepare-kokoro.py
./gradlew testDebugUnitTest lintDebug assembleDebug
bash scripts/check-csv.sh
```

SDK 用 `ANDROID_HOME` 或 `local.properties` 的 `sdk.dir` 指定。产物 `app/build/outputs/apk/debug/app-debug.apk`。本次 APK 使用此前交付的调试签名；其他机器自动生成的调试签名不同，不能直接覆盖本次安装。签名密钥不在源码中。GitHub Actions 提供自动构建和检查。
